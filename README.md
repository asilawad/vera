# Vera

**جودة تحملها معك**

تطبيق Vera لبيع الحقائب بأنواعها: مدرسية، أطفال، لابتوب، سفر وغيرها. تصميم أنيق بالعنابي والذهبي وتجربة تسوق سلسة باللغة العربية.

## المميزات

- شاشة رئيسية فيها سلايدر عروض وأقسام ومنتجات مميزة ووصل حديثًا والأكثر مبيعًا
- تصفح الأقسام والبحث عن المنتجات
- تفاصيل المنتج: معرض صور، اختيار المقاس واللون، التقييمات
- سلة المشتريات وإتمام الطلب
- المفضلة
- تسجيل الدخول وإنشاء حساب وتعديل الملف الشخصي
- متابعة الطلبات وتفاصيلها
- تصميم متجاوب مع مختلف أحجام الشاشات

## التقنيات المستخدمة

- Flutter
- GetX لإدارة الحالة والتنقل
- GetStorage للتخزين المحلي
- Cached Network Image لتحميل الصور وتخزينها مؤقتًا
- Flutter ScreenUtil للتجاوب

## التشغيل

```bash
flutter pub get
flutter run
```

## هيكل المشروع

```
lib/
  api/              إعدادات الاتصال
  getx_controller/  إدارة الحالة
  models/           النماذج
  preferences/      التخزين المحلي
  screen/           الشاشات
  utils/            الألوان والثيم والتجاوب
  widget/           المكونات المشتركة
assets/
  brand/            الشعار وأيقونات التطبيق
  fonts/            الخطوط
```
